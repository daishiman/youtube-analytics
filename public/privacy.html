YouTube分析

プライバシーポリシー

施行日: 2026年9月24日

1. 取得する情報

  • Google アカウントのメールアドレスと、その確認状態（Google ログイン時。スコープは openid と email）
  • 所属するワークスペース（チャンネルごとの作業場所）と役割（オーナー・編集者・閲覧者）
  • ログインのためのセッション情報（Cookie。サーバ側にはハッシュ値のみを保存）
  • オーナーが YouTube と連携した場合の、そのチャンネルの情報と分析データ、手動で取り込んだ CSV・字幕・画像の原本と取込履歴

2. 利用目的

ログインと本人確認、ワークスペースとメンバーの管理、YouTube チャンネルの分析結果の表示のためにだけ利用します。広告や第三者への販売には利用しません。

3. 共有される範囲

ワークスペースのオーナーが招待したメンバーには、そのワークスペースのチャンネルのデータが表示されます。招待はオーナーが指定したメールアドレスの Google アカウントでのみ受理でき、メンバーの役割（編集者・閲覧者）に応じて操作できる範囲が異なります。

4. Google の API サービスの利用

本サービスは YouTube API Services を利用します。本サービスの利用には YouTube 利用規約への同意が必要です。Google による情報の取扱いは Google プライバシーポリシーをご覧ください。連携の解除は Google のセキュリティ設定からも行えます。

5. 保存と削除

  • セッションは最長30日で失効します。ログアウトすると直ちに無効になります。
  • 招待リンクは7日で失効し、1回だけ使えます。サーバには招待トークンのハッシュ値のみを保存します。
  • YouTube API から取得する指標以外のデータについて、30日以内の削除または再取得を行う日次収集機能は準備中です。
  • 設定画面の「連携解除」は旧チャンネルの保存データの削除を予約し、専用の自動処理が原本と取込履歴を削除します。完了するまで新しいチャンネルは連携できません。
  • 「データを削除」はテナント全体の削除依頼を記録し、7日以内の期限を設定します。テナント全体の自動削除は準備中です。削除完了の確認や早急な削除をご希望の場合は下記の運営者へご連絡ください。

6. Cookie

ログイン状態の維持と、ログイン処理の改ざん防止のためにだけ Cookie を使います。解析や広告の Cookie は使いません。
