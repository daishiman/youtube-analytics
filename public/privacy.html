プライバシーポリシー

運営者: 万壽本　大嗣
施行日: 2026年9月24日

1. 取得する情報

  • Google アカウントのメールアドレスと、その確認状態（スコープ openid と email）
  • 所属するテナント（チャンネルの作業場所）と役割（オーナー・編集者・閲覧者）
  • ログインのためのセッション情報（Cookie。サーバ側にはハッシュ値のみを保存）
  • 新しくテナントを作る方のログイン時に、YouTube の次の2つの権限を読み取り専用で求めます。どちらも閲覧だけで、動画の投稿・編集・削除はできません。
    • YouTubeチャンネル情報の閲覧（https://www.googleapis.com/auth/youtube.readonly）
    • YouTube Analyticsレポートの閲覧（https://www.googleapis.com/auth/yt-analytics.readonly）
    招待されたメンバーのログインでは、メールアドレス以外は求めません。一部の権限を許可しなかった場合もログインでき、あとから設定画面の「再連携」で追加できます。
  • 上記の許可にもとづく更新用トークン（暗号化して保存し、平文では保存しません）と、そのチャンネルの分析データ
  • 利用規約とプライバシーポリシーに同意した版と日時（規約が改定されたときに、次回ログインで同意し直していただくため）

2. 利用目的

ログインと本人確認、テナントとメンバーの管理、YouTube チャンネルの分析結果の表示のためにだけ利用します。広告や第三者への販売には利用しません。

3. 安全のための約束

  • OAuthは読み取り専用です。本サービスがあなたの YouTube チャンネルを変更することはありません。
  • データは利用者ごとに分離して保存し、テナントのメンバー以外には表示しません。
  • 本サービスはクラウドの無料枠で運用しており、利用料金はかかりません。

4. 共有される範囲

テナントのオーナーが招待したメンバーには、そのテナントのチャンネルのデータが表示されます。招待はオーナーが指定したメールアドレスの Google アカウントでのみ受理でき、メンバーの役割（編集者・閲覧者）に応じて操作できる範囲が異なります。

5. Google の API サービスの利用

本サービスは YouTube API Services を利用します。本サービスの利用には YouTube 利用規約への同意が必要です。Google による情報の取扱いは Google プライバシーポリシーをご覧ください。連携の解除は Google のセキュリティ設定からも行えます。

6. 保存と削除

  • セッションは最長30日で失効します。ログアウトすると直ちに無効になります。
  • 招待リンクは7日で失効し、1回だけ使えます。サーバには招待トークンのハッシュ値のみを保存します。
  • YouTube API から取得した指標以外のデータは、取得から30日以内に削除または再取得します。
  • データ削除の依頼を受けた場合は、7日以内に削除します（設定画面の「データを削除」は連携機能とあわせて提供します）。

7. Cookie

ログイン状態の維持と、ログイン処理の改ざん防止のためにだけ Cookie を使います。解析や広告の Cookie は使いません。
