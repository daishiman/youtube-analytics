# 残課題リスト

- [分類: 機能] `docs/analysis/youtube-official-data-scope.md` の広域カバレッジ契約に沿って、Analyticsの視聴者属性・維持曲線・収益、Data APIのその他属性と累積統計を権限別に収集する。チャンネル/動画の日次基本指標、流入元/端末/国の原値閲覧、動画メタデータの一部、Reportingの利用可能種別発見・原本収集は実装済み。実チャンネルでの稼働・欠損・再取得の検証と、収益系の追加OAuth同意が必要
- [分類: 機能] Reportingのリーチ基本以外とStudio CSVの残る列を動画×期間・動画×日・チャンネル×日に正規化し、正式M1〜M10と動画別詳細・チャンネル構成比へ反映する。未知列は原本に保持し未マッピングと表示する。リーチ基本の動画別CTRは数値の原値のみ、Studio CSVの視聴回数/エンゲージビュー別取込・原本/列対応閲覧、事業週次CSVのファネル反映は実装済み。Studioの実サンプルでは長さと平均視聴時間の形式を確定したが、表データの集計期間はCSV本文にない。Reportingの実CSV見本でCTRの単位を確定する必要がある
- [分類: 運用] テナント/動画数の増加に応じた Data API quota・Queue操作・D1行書込の実測とバックオフを追加する。現行実装は変更のない日次行の再書込を抑え、サムネイル送信量に概算の予算を設けているが、全レポートを集める上限は実測で確定していない
- [分類: 運用] `feat-retention-ops` の期限超過予約の通知・運用対応を完成させ、公開環境でQueue・Cron・削除後のR2再掃除を検証する。テナント全削除、Reporting原本の30日ごとの認可再確認・失効時削除、字幕原本の30日保持、チャンネル解除後の旧履歴・R2原本削除はローカル実装・テスト済み。動画の削除状態を30日ごとに再確認する経路は別途監査する
- [分類: 機能] `feat-csv-media-ingest` で受付済み字幕・画像を解析し、期間・行数・失敗理由を確定する — この feature は原本保存と「処理待ち」履歴までを担当するため
- [分類: 機能] 専用の動画画面で、1本ごとの維持曲線・離脱点・コメント・場面を実データから表示する — 現在のダッシュボードでは期間を保って1本に絞ったKPI・日次推移まで表示する
- [分類: 機能] テナントごとの Google Cloud プロジェクトで YouTube Data API quota を計測できる方法を確定する — 現在の全体カウンタは各プロジェクトの利用率を表さないため、設定画面には「未取得」と表示する
- [分類: 機能] D1書込行数（索引更新を含む）とテナントごとの字幕取得数の実測処理を日次収集に接続する — 未計測を0件や全体合計として表示すると誤警告になるため
- [分類: UX] 既存の青・ティールのブランド画面を保ったまま、参照カタログへの準拠項目を評価する — 自動色移行は既存ブランドの意味を変えるため
