## フェーズ3: 改善の対象と依存

1. APIの視聴率集計を長尺動画に限定し、対象期間に計算可能なCSVがない状態を正しく判定する。正式M1の算式に必要な列は現在のCSV日次テーブルにないため、現行の計算式を開示し、取込機能側の依存として残す。
2. ダッシュボードでは対象追従区画と全体固定区画を明記する。選択動画の全動画に占める割合は同じ `video_metrics` の値同士で計算する。公式チャンネル合計には削除済み動画も含まれるため、この分母と混ぜない。
3. 個別線の表示を制御しつつ、全動画の値は表で残す。動画行から同じ期間の1本表示へ移動する。
4. 既存の構成比と詳細にある重複表示をまとめ、ヘッダーとサイドバーをスクロール中も表示する。
