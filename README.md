# youtube-analytics

自分の YouTube チャンネルのデータ（YouTube Studio / YouTube Analytics API）と連携して分析し、次の施策を考えるための Web システム。

## 目的

- チャンネル・動画ごとの指標（再生数、視聴維持率、インプレッション CTR、登録者の増減など）を集約して可視化する
- 伸びた動画・伸びなかった動画の傾向を比較する
- 分析結果から次に打つ施策の候補を整理する

## ステータス

リポジトリ作成直後。要件定義・技術選定はこれから。

## 注意

OAuth クライアントシークレットやトークンなどの認証情報はコミットしない（`.env` などは `.gitignore` 済み）。
